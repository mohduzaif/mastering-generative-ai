# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/mohduzaif/mastering-generative-ai.git
```

Move inside repository

```bash
cd mastering-generative-ai
```

Install dependencies

```bash
pip install -r requirements.txt
```

---

## Environment Variables

Create a `.env` file.

Example

```env
OPENAI_API_KEY=your_openai_key
GOOGLE_API_KEY=your_google_api_key
GROQ_API_KEY=your_groq_api_key
```

> **Important:** Never commit your `.env` file to GitHub. Make sure it is included in `.gitignore`.
